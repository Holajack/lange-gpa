# Ti Boujon — Haitian Creole Recording Script

**~210 short phrases · about 15 minutes per voice.** This is the complete Kreyòl audio for Nurilang.

## How to record
1. Find the quietest room you can. Phone voice-memo app is perfect.
2. Read each numbered line **out loud, naturally** — full Haitian Creole, the real French-flavored pronunciation.
3. **Pause about 1 second between each line** (this lets the importer split them automatically).
4. If you flub one, pause, then just say it again — we can trim.
5. A **woman and a man** can each record the whole list as a separate file — send both.
6. Send the file(s) however is easiest (AirDrop, text, email). I'll handle the rest.

Tip: the **gloss in (parentheses)** is only to tell you which word — don't read it, just say the Kreyòl.


### Session cues

1. **Bonjou! Mwen rele Ti Boujon.**  _( Hi! I'm Ti Boujon. )_
2. **Koute.**  _( Listen. )_
3. **Ankò.**  _( Again. )_

5. **Bravo! Ou fè sa byen!**  _( Bravo! You did well! )_
6. **Ann kòmanse!**  _( Let's begin! )_
