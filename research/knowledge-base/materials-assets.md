## 1. Original GPA materials on disk

### 1.1 `2. Phase1 BW Graphics Feb 2023.pdf` — the Phase 1 Graphics Resource Packet
- **101 pages, 63.6 MB** (image-heavy scans). Footer on every page: *"Phase 1 Graphics version Sept 2016 - drawings by Angela Thomson, copyright September 2016, all rights reserved. Informal copying and distribution freely allowed. Please obtain permission for formal publication."*
- **Page 1 — "Phase 1 Resources: Picture Set and Shopping List"**: instructions (color the drawings, laminate, cut apart, keep in coded envelopes; back-code pictures like `1.3.5` = Phase 1, Meeting plan 3, Activity 5) plus a physical shopping list: toy creatures (farm/wild animals, insects, dolls), toy objects (dollhouse+family, money, cars, fruits/veg, legos), tools, grocery items, stationery, personal care, containers, clothing, dishes, kitchen utensils, outdoor items (rocks, sand, flowers). Notes the "town" scene reflects **post-Soviet Central Asia** city life and should be localized.
- **Pages 3–10 — "A Set of Lexicarry-Like Pictures" by Angela Thomson**: hand-drawn B&W comic panels with EMPTY speech bubbles, numbered 1A–20 (greetings, leave-taking, older-person variants, asking/giving name, "I don't understand," what is this/that, gratitude, "what is he/I/you/they doing?", visitor at door, asking for restroom, store item + price, offering/getting help, apology, sneeze response, warning, birthday greeting, permission, offering/declining more, reprimand/"don't forget"). Used for the pointing game: nurturer says an expression, GP points to which bubble/person is saying it.
- **Middle sample (pages 45–52)**: per-meeting picture sets — Meeting plan 9 Game 6: clothing cut-outs across 3 pages (dress, shirts, pants, coats, boots, gloves, Central-Asian vest/caps; "Also available in colour"); Meeting plan 10 Game 3: 12-panel daily-actions grid (listen, read, turn around, eat/taste, smell, write, draw, sweep/work, play, sleep, wake); Meeting plan 11 Game 1: sound-discrimination pictures (example set for hard Kazakh sounds — "for your language, you will need to make your own"); Meeting plan 11 Game 2: 25 emotion/state faces with an English key (happy, sad, angry, frightened, surprised, embarrassed, worried, kind, cruel, sly, mean, stern, jolly, grieving, sleepy, exhausted, thirsty, hungry, cold, hot, sick, injured, messy, dirty, bored); Meeting plan 11 Games 3–5: stick-figure states and kinship+emotion combos.
- **Phase used**: Phase 1 (both 1A meetings 1–15 and 1B meetings 16–40). This is the visual source the app's card deck re-implements with original art.
- **Style**: deliberately simple amateur line drawings, no text in pictures, meant to be colored/cut/localized.

### 1.2 `Lexicarry-like strips-Key.pdf` (2 pages) + `Lexicarry-like strips-Key.docx` twin
- The text KEY for strips 1A–19 of the graphics packet (list reproduced above). The .docx (14.5 KB) is the editable twin of the same content.
- Method note inside: don't translate your own expressions — show the situation and ask what a host person would say. Recommends buying the commercial **Lexicarry book by Moran (lexicarry.com)** (~60 language functions) as a fuller resource.
- **Phase used**: Phase 1 (social-expression "survival/power phrases" activity, ~10 expressions learned in the first month), revisited in Phases 2–3 for discussing variants and role-play.

## 3. Audio library — `public/audio/`

**Structure**: `public/audio/{lang}/{itemId}.mp3` (the bare word) + `{itemId}-q.mp3` (the "Where is …?" question), plus a single top-level `manifest.json` (42.9 KB).

- **Manifest schema**: `{ "<lang>": { "<exact spoken text>": "/audio/<lang>/<file>.mp3" } }` — keys are the literal utterances (e.g. `"яблоко"`, `"Где яблоко?"`, `"りんごはどこ？"`). Entry counts: **en 210, ja 210, ru 484**. (ru has one manifest key per Russian text; several map to the same file where a word doubles as its own label, hence 484 keys → 488 files.)
- **Files on disk**: en **210** (112 words + 98 questions), ja **210** (identical file set to en), ru **488 real files** (251 words + 237 questions — covers the full 28-domain deck including all prefixed categories). The `ru/` dir also contains 766 macOS AppleDouble `._*` junk files worth cleaning.
- **Generation**: `scripts/generate-audio.mjs` — **ElevenLabs TTS**, model `eleven_multilingual_v2`, idempotent. Voice casting: ru = Bella (`hpp4J3VqNfWAUOO0d1Us`) as "Listik" the matryoshka buddy; en = `JBFqnCBsd6RMkjVDRZzb` ("Nuri"); ja reuses the Bella voice id. Each language has 6 session cues (greeting/listen/again/point/praise/begin) + per-word + per-question clips + 8 TPR commands. A `maleVoiceId` option (Brian `nPczCjzI2devNBz1zQrb`) can generate a parallel male set into `{lang}/m/` + `manifest["{lang}-m"]` — **no m/ sets exist on disk yet**.
- **Playback**: `src/lib/tts.ts` fetches the manifest lazily and plays pre-generated clips first; **anything not in the manifest falls back to browser speech synthesis**, so all 19 UI languages "speak" even though only en/ru/ja have real clips.
- **Human recordings — Haitian Creole plan** (`docs/HT-RECORDING-SCRIPT.md`): ElevenLabs has **no native Kreyòl model** (multilingual_v2 reads it French-ish), so `ht` TTS is deliberately disabled. The script "Ti Boujon" contains **210 numbered lines** (~15 min per voice): 6 session cues, then word + "Kote X?" pairs for all 98 original deck items grouped Food/Animals/Home/Body/Traveling/Family/Sport/Health/Nature/Work, then 8 TPR commands. Protocol: quiet room, phone voice memo, ~1 s pause between lines, one female + one male speaker each recording the whole list. Ingestion: `scripts/ingest-ht-audio.mjs` splits the continuous recording on pauses with ffmpeg (tunable `--silence`/`--mindur`), loudness-normalizes, writes `public/audio/ht/*.mp3` and updates the manifest; `public/ht-recording.html` is a teleprompter page in phrase order. **Status: `public/audio/ht/` does not exist yet — recordings not received/ingested.**
- **Coverage summary**: ru = complete (245-item deck + cues + TPR, female voice only); en/ja = original 98-item deck only (no prefixed categories); ht = scripted but empty; the other 15 languages = browser TTS fallback only.

## 4. Story materials (Phases 2–3)

- **Source bibliography**: `Phase+2+Storybooks.pdf` (section 1.3 above) — tiered Introductory → Advanced with ratings and per-book usage notes.
- **Scans on hand**: the 29-folder wordless-book JPEG set (section 1.4) — matches the "Owner's local scan set" list in the research doc; includes Sir Andrew and Ethiopian wordless stories which aren't in the Thomson bibliography. Robot scan folder is empty (notes file only).
- **Curation plan** (`research/phase2-3-story-library.md`):
  - Phase 2 usage: nurturer narrates a wordless book, grower listens/points, later retells; advance tiers when fewer than ~7–8 new words/hour.
  - Phase 3 usage: "Stuff-We-Both-Know" shared stories — fairy tales (Cinderella/Goldilocks), religious stories (David & Goliath, Noah), folk tales, biographies — plus wordless animation: **Tom & Jerry, Mr. Bean, Max7.org "No Language" animations** as streamable Phase-3 material.
  - Planned app feature: a **Story Library** screen with tiered shelves; story cards showing cover + tier + stars + phase fit + "no words" badge; a wordless-story player (page-turner where the nurturer records narration per spread, feeding the grower's re-living audio like the Talking Picture Dictionary); unlicensed titles shown as "bring this book" suggestions; Lexicarry-like strips power the "who is saying…?" game.
  - **None of this is digitized in-app yet** — no story assets exist under `public/`, and the copyrighted scans must stay out of the product.

## 5. Copyright / permission status

- **Thomson phase guides & graphics packet**: "copyright … all rights reserved. **Informal copying and distribution freely allowed. Please obtain permission for formal publication.**" (footer on every graphics page; equivalent notices in phase2/phase4 guides). A commercial app is "formal publication" territory ⇒ permission needed to reproduce any of it.
- **App strategy** (`docs/THOMSON-PERMISSION-EMAIL.md`, draft email to Greg & Angela Thomson): Nuri implements the *method* (not copyrightable) with **its own original card art, audio, word selections and copy** — none of the phase-guide text, drawings, or Lexicarry-style strips reproduced; footer credit "Built on the Growing Participator Approach by Greg & Angela Thomson" + link to growingparticipation.com; no claim of endorsement. The email asks for (1) permission to describe Nuri as GPA-based in marketing, (2) optional licensing of the phase guides / Graphics Resource Packet for in-app use, (3) guidance/partnership. Notes: send BEFORE ad spend or "Nuri" trademark filing; if declined, drop nominative GPA references from marketing; do a Class 9/41 trademark clearance on "Nuri."
- **Lexicarry proper**: commercial book by Moran (lexicarry.com) — referenced, not owned; the packet's "Lexicarry-like" strips are Angela Thomson's own drawings (same notice as above).
- **Wordless book scans**: third-party copyrighted works (Mercer Mayer, Krahn, Ormerod, Baker, Goodall, etc.), scanned as out-of-print stop-gaps with a "buy it if reprinted" honor clause. **Cannot ship in-app**; usable only as personal/owner reference. In-app plan is metadata + "bring this book" + public-domain/permitted media (Max7.org etc. — note Tom & Jerry / Mr. Bean streaming rights would themselves need care).
- **research/phase*.txt**: OCR of copyrighted guides — internal reference only, flagged as such in phase1-authentic-inventory.md.
- **App's own assets** (237 webp cards, ElevenLabs mp3s, vocab lists, HT script): original to the project; ElevenLabs output subject to their commercial license terms; future ht clips are recordings of the owner's own contacts (voice-release consent worth documenting).
